# Inbound IT Support Call Script

## 1. Opening
"Good morning/afternoon, IT Service Desk. My name is [first name]. How may I help you?"

## 2. Understand the issue
- "Could you describe what you were trying to do when the issue occurred?"
- "What message do you see on the screen?"
- "When did this first happen?"
- "Is anyone else experiencing the same issue?"
- "Is there a workaround available?"

## 3. Confirm scope and impact
- Identify the affected device, application or service using approved non-sensitive identifiers.
- Establish whether one user, a team, or multiple departments are affected.
- Ask whether the issue is preventing an important work activity.
- Do not ask for passwords, MFA codes, or patient details.

## 4. Explain next steps
"Thank you. I have recorded the symptoms and the checks we discussed. I will perform the approved first-level checks. If specialist access is required, I will route the incident to the appropriate team and keep the ticket updated."

## 5. Before ending the call
- Summarize the issue.
- Confirm the ticket reference using the fictional lab ID.
- Explain the next action and expected follow-up method.
- Ask whether the user has any other IT issue to report.
- Close politely.

## 6. Practice evaluation
After rehearsing, record whether you:
- Used a professional greeting.
- Asked open and clarifying questions.
- Established impact and scope.
- Avoided collecting sensitive information.
- Summarized the issue and next action clearly.
