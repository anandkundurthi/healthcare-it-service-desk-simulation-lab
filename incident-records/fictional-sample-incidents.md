# Fictional Sample Incident Records

These are examples for learning the format. They are not evidence of real support work or completed troubleshooting.

## HSD-TRAIN-001 — Repeated Microsoft 365 sign-in prompt
- Caller: Fictional user Casey Patel
- Category: Account Access
- Impact: Low
- Urgency: Medium
- Priority: To be determined using the selected practice matrix
- Symptoms: Repeated sign-in prompt in one fictional work application.
- Initial triage: Establish application, exact error, time started and whether other services are affected.
- Safety: Never request password or MFA code.
- Next action: Route to Identity & Access Support if account-specific investigation is required.
- Outcome: Example only; not tested.
